# SPINE — тестовое задание Technical Level Designer

Прототип модульной системы смены ракурса камеры с тест-кейсами на уровне.

- **Движок:** Unreal Engine **5.8.4**
- **Реализация:** только Blueprints
- **Автор:** Владислав Пономаренко

> Подробная документация по системе (параметры, инструкции для LD/GD, примеры, дизайнерские сценарии): **[CameraSystem.md](CameraSystem.md)**

---

## Быстрый старт

1. Открыть `SPINE_TLD_Test.uproject` в Unreal Engine 5.8.4.
2. Карта `L_TestLevel` открывается автоматически (`Content/SpineTest/Maps/L_TestLevel`).
3. Нажать **Play**.

[скриншот: общий вид уровня сверху]

## Управление

| Действие | Клавиши |
|---|---|
| Движение | W A S D |
| Камера | Мышь |
| Прыжок | Space |
| Debug: режим «Коридор Sifu» / «Top-Down» / стандартная камера | 1 / 2 / 0 (работают только в редакторе) |

Управление адаптируется под текущий режим камеры:

| Режим | Движение | Мышь |
|---|---|---|
| Стандартная камера | относительно камеры | вращает камеру |
| Коридор Sifu (вид сбоку) | A / D — вдоль коридора, W / S отключены | отключена |
| Top-Down (вид сверху) | W — «вверх по экрану», остальное аналогично | отключена |

**Фиксация направления на границе зон.** Когда камера меняется, направление движения сохраняется, пока игрок держит клавиши. Игрок не разворачивается и не вылетает обратно из зоны. Управление переключается на новую камеру, как только игрок отпустил клавиши или повёл мышью.

## Структура уровня

Уровень — цепочка тест-зон по ТЗ. Игрок идёт вдоль оси X.

```
Start ─┃─ Коридор Sifu + NPC ─┃─ Буфер ─┃─ Top-Down: комната A │ комната B + NPC ─┃─ Финал
       W1                     W2        W3                                        W4
┃ — полупрозрачная стена: пропускает игрока, блокирует NPC
│ — перегородка с проёмом между комнатами A и B (камера переезжает из комнаты в комнату)
```

| Зона | Камера | Что проверяется |
|---|---|---|
| Start | стандартная | — |
| Коридор Sifu | вид сбоку | режим «Коридор», управление вдоль оси, NPC ограничен стенами W1/W2 |
| Буфер | стандартная (возврат) | выход из режима, возврат управления мышью |
| Top-Down, комнаты A и B | фиксированная сверху над каждой комнатой | режим «Top-Down», смена камеры между соседними зонами без промежуточной стандартной камеры, NPC ограничен стенами W3/W4 и проходит между комнатами |
| Финал | стандартная (возврат) | — |

Уровень можно пройти в обе стороны: все переходы работают и в обратном порядке.

## Ограничения и известные особенности

- **Приоритет зон** — «последняя вошедшая главная». Отдельного числового приоритета нет.
- **Центр фиксированной камеры** — позиция актора зоны. Если зона собрана из нескольких фигур, камера повиснет над точкой актора, а не над центром всех фигур.
- **Во время перехода камеры** коллизия spring arm отключена: камера может на мгновение пройти сквозь геометрию. Это сделано намеренно, иначе кадр «прыгает».
- **NPC** — простой компаньон: следует по навмешу, без обхода других NPC и без боевой логики.
